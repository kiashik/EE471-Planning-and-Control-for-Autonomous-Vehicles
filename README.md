EE 471. Planning and Control for Autonomous Vehicles Laboratory. (1 unit)
Hands-on laboratory work in planning and control for autonomous vehicles and self-driving cars, combining
virtual simulations with hardware experiments on a vehicle platform. Topics include autonomous vehicles
hardware/software architectures, sensor interfacing and calibration (camera, LiDAR, IMU), vehicle dynamics
and longitudinal/lateral control, state estimation using Kalman filters, environment interpretation via LiDAR,
vision-based line detection, trajectory planning, vehicle control strategies for lane keeping, and safety assurance.
Integrates theoretical concepts with practical applications.
